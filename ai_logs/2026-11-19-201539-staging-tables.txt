  Question 1: How should duplicate answers be counted?

  2,082 cases have the same question answered 2–5 times in one sitting, all at
  the same instant. In 965 of them, the copies disagree about whether it was
  correct.

  - Option 1 (my recommendation): one answer per question per sitting, counted
    correct only if every copy says correct.
    - Each question counts once, so no answer is weighted up to 5×.
    - It's deterministic: there's no tie to break, so re-runs always agree.
      Picking "the first copy" by response_id would be arbitrary, because the
      timestamps are identical.
    - When we can't tell, it errs low rather than inflating a pupil's score.
    - It affects about 1.6% of answers. We'd keep a count of conflicting
      duplicates so it stays visible.
  - Option 2: one answer per question, counted correct if any copy says correct.
    Same dedupe, but the benefit of the doubt goes to the pupil.
  - Option 3: drop the 965 conflicting groups entirely. Clean, but it throws
    away real evidence that the pupil answered.
  - Option 4: keep every row. No logic needed, but it double-counts questions,
    so I'd advise against it.

  Which do you prefer?

      resets naturally when the year group changes.
